Hugo resume site for Ashish K. Singh

This repository contains the content and configuration for a Hugo-based multi-page resume. The site is built in GitHub Actions and published to GitHub Pages (gh-pages branch) automatically on pushes to main.

Theme: hugo-PaperMod (add as a submodule: git submodule add https://github.com/adityatelange/hugo-PaperMod themes/hugo-PaperMod)
